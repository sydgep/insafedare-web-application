# Pipeline Components

[← Back to the main README](../README.md)

INSAFEDARE provides reusable components for constructing tabular-data and medical-image pipelines. Each component performs a defined operation and can be connected to compatible components through the graphical pipeline editor.

## Data Ingestion

| Component | Purpose | Input Parameters | Output |
|---|---|---|---|
| **File Extraction** | Ingests data from supported source files. |`Input File`: filename (.csv, .json, .parquet, .txt, .xls, .xlsx, .gzip or .zip). <br>`Columns`: columns to extract (all columns will be extracted if empty). | Name.parquet (Name is specified by the user) |
| **Database Extraction** | Connects to a PostgreSQL database and extracts selected columns from a table. | `Host`, `Port`, `Username`, `Password`, `Database Name`, `Schema`, `Table Name`, `Columns` | Name.parquet (Name is specified by the user)|
| **API Extraction** | Retrieves records from an API response and extracts the requested fields. |`url`: API endpoint.<br>`Record Path`: path to the records.<br>`Columns`: fields to retain. | Name.parquet (Name is specified by the user) |

Regardless of the source format, the component writes the extracted dataset to a **Parquet file** for use by downstream pipeline components.

## Data Integration and Preprocessing

| Component | Purpose | Input Parameters | Output |
|---|---|---|---|
| **Merge Data** | Combines two datasets using a common column. | `Merge On`: common column.<br>`Merge How`: `left`, `right`, `inner`, or `outer`. | Name.parquet (Name is specified by the user) |
| **Merge on Date** | Combines two datasets by aligning records according to identifiers and dates. | `Merge On`: common identifier.<br>`Date Column Base`: date column in the base dataset.<br>`Date Column Merge`: date column in the dataset to merge.<br>`Merge Direction`: `nearest`, `forward`, or `backward`. | Name.parquet (Name is specified by the user) |
| **Count Measurement** | Counts records within groups and creates a new measurement-count column. | `Group By`: column used to group records.<br>`Output Column Name`: name of the generated count column. | Name.parquet (Name is specified by the user) |
| **Extract Measurement** | Extracts records associated with a specified measurement. | `Name Column`: column containing measurement names.<br>`Value Column`: column containing measurement values.<br>`Measurement Name`: measurement to extract.<br>`Match Type`: `startswith`, `exact`, or `contains`. | Name.parquet (Name is specified by the user) |
| **Expand Feature** | Expands a compound feature into separate columns. | `Feature`: column to expand.<br>`Expand On`: separator or criterion used to split the feature. | Name.parquet (Name is specified by the user) |
| **Select Cohort** | Selects records belonging to a defined population or clinical cohort. | `Target Column`: column containing the cohort criterion.<br>`ID Column`: record or patient identifier.<br>`Match On`: value or code to match.<br>`Match On Length`: number of leading characters used for matching. | Name.parquet (Name is specified by the user) |
| **Feature Selection** | Retains only the columns required for subsequent processing. | `Columns`: columns to retain. | Name.parquet (Name is specified by the user) |
| **Label Encoder** | Converts categorical values into numerical labels. | `Columns`: categorical columns to encode. | Name.parquet (Name is specified by the user) |
| **One-Hot Encoder** | Converts categorical variables into binary indicator columns. | `Columns`: categorical columns to encode. | Name.parquet (Name is specified by the user) |
| **Convert to Numeric** | Converts compatible columns into numerical data types. | `Columns`: columns to convert. | Name.parquet (Name is specified by the user) |
| **Drop NaN** | Removes records containing missing values. | No component-specific parameters. | Name.parquet (Name is specified by the user) |
| **Missing-Value Imputation** | Automatically replaces missing numerical values with the median and categorical values with the mode. | `Excluded Columns`: columns that must not be imputed. | Name.parquet (Name is specified by the user) |
| **Missing-Value Removal** | Removes records containing unresolved missing values. | No component-specific parameters. | Name.parquet (Name is specified by the user) |
| **Rename Columns** | Renames selected columns to standardize the dataset schema. | `Old Columns`: current column names.<br>`New Columns`: corresponding replacement names. | Name.parquet (Name is specified by the user) |
| **OMOP CDM Transformer** | Maps source healthcare data to OMOP Common Data Model concepts and produces transformation metadata. | `Base Input`, `Concept File`, `User Column Descriptions`, `Number of Rows`, `OMOP Hub API Key`, `Similarity Threshold`, `Enable Note NLP`, `Use Embeddings`, `NLP Entity Types`, `NLP Maximum Words`, `Export Format`, `Embedding Model`, `Standard Concepts Only`, `OMOP Output Directory`, `Output Metadata`, `Output OMOP Mapping`. | OMOP-formatted tables, metadata, and mapping files |
| **OMOP Table Merger** | Combines generated OMOP tables into a consolidated CDM package. | `OMOP Tables Output Directory`, `Shared Folder`, `Format`, `CDM Holder`, `Vocabulary Version`, `CDM ETL Reference`, `Source Documentation Reference`. | Consolidated OMOP CDM output |

## Privacy-Preserving Transformations

| Component | Purpose | Input Parameters | Output |
|---|---|---|---|
| **De-identification** | Removes columns containing direct identifiers. | `Identifier Columns`: direct-identifier columns to remove. | Name.csv and Name.parquet (Name is specified by the user) |
| **Anonymization** | Transforms identifying or quasi-identifying values using a selected anonymization strategy. | `Identifier Column`: column to transform.<br>`Strategy`: anonymization method.<br>`Precision`: precision used by the selected strategy.<br>`Interval`: generalization interval. | Name.csv and Name.parquet (Name is specified by the user) |
| **Gaussian Copula Synthesizer** | Generates synthetic tabular data by learning statistical distributions and dependencies. | No component-specific parameters. | Name.csv and Name.parquet (Name is specified by the user) |
| **VAE Synthesizer** | Generates synthetic tabular data using a variational autoencoder. | `Epochs`: number of training epochs (default: `400`).<br>`Batch Size`: number of records processed per batch (default: `100`).<br>`Loss Factor`: weight applied to the loss function (default: `2`). | Name.csv and Name.parquet (Name is specified by the user) |
| **CTGAN Synthesizer** | Generates synthetic tabular data using a conditional generative adversarial network. | `Epochs`: number of training epochs (default: `400`).<br>`Batch Size`: number of records processed per batch (default: `100`). | Name.csv and Name.parquet (Name is specified by the user) |
| **CopulaGAN Synthesizer** | Generates synthetic tabular data by combining copula-based modelling with a generative adversarial network. | `Epochs`: number of training epochs (default: `400`).<br>`Batch Size`: number of records processed per batch (default: `100`). | Name.csv and Name.parquet (Name is specified by the user) |

## Evaluations

| Component | Purpose | Input Parameters | Output |
|---|---|---|---|
| **Statistical Evaluation** | Compares the statistical distributions and relationships of original and transformed datasets. | `Input File 1`: original dataset.<br>`Input File 2`: transformed or synthetic dataset. | Name.parquet (Name is specified by the user) |
| **Data Quality Evaluation** | Compares the quality of original and transformed datasets using measures related to completeness, validity, consistency, and data usability. | `Input File 1`: original dataset.<br>`Input File 2`: transformed or synthetic dataset. | Name.parquet (Name is specified by the user) |
| **Overfitting Evaluation** | Evaluates whether a synthetic dataset reproduces records or patterns from the original dataset too closely. | `Input File 1`: original dataset.<br>`Input File 2`: synthetic dataset. | Name.parquet (Name is specified by the user) |
| **Attribute Inference Attack** | Evaluates whether sensitive attributes in a synthetic dataset can be inferred from known quasi-identifying attributes. | `Input File 1`: original dataset.<br>`Input File 2`: synthetic dataset.<br>`Quasi-Identifiers`: attributes assumed to be known to an attacker.<br>`Sensitive Attributes`: confidential attributes the attacker attempts to infer.<br>`Attack Model`: model used to perform the attack (default: `random_forest`). | Name.parquet (Name is specified by the user) |
| **Record Linkage Attack** | Estimates whether records in a synthetic or transformed dataset can be linked to records in the original dataset using quasi-identifying attributes. | `Input File 1`: original dataset.<br>`Input File 2`: synthetic or transformed dataset.<br>`Quasi-Identifiers`: attributes used to link records. | Name.parquet (Name is specified by the user) |
| **Distance to Closest Real Record** | Measures the distance between each synthetic record and its closest record in the original dataset to identify potential privacy risks. | `Input File 1`: original dataset.<br>`Input File 2`: synthetic dataset. | Name.parquet (Name is specified by the user) |
| **Utility Evaluation** | Evaluates the predictive utility of synthetic or transformed data by training a selected classification or regression model and comparing its performance against a real-data baseline using Train-on-Real, Test-on-Real (TRTR) and Train-on-Synthetic, Test-on-Real (TSTR) experiments. The selected model determines whether classification or regression is performed. The selected metrics must be compatible with the model type. | `Input File 1`: original dataset.<br>`Input File 2`: transformed dataset.<br>`Feature Columns`: predictor variables.<br>`Target Column`: variable to predict.<br>`Train Size`: (default: `0.7`).<br>`Model Name`: classification or regression.<br><br>**Classification models:** `LogisticRegression`, `RandomForestClassifier`, `GradientBoostingClassifier`, `SVC`.<br>**Classification metrics:** `accuracy`, `f1`, `roc_auc`.<br><br>**Regression models:** `LinearRegression`, `RandomForestRegressor`, `GradientBoostingRegressor`, `SVR`.<br>**Regression metrics:** `r2`, `rmse`.<br><br> | Name.parquet (Name is specified by the user) |
| **K-Anonymity** | Verifies whether every quasi-identifier combination is shared by at least the expected number of records. | `Input File 1`: anonymized dataset.<br>`Quasi-Identifiers`: attributes used to form equivalence classes.<br>`Expected K`: minimum required equivalence-class size (default: `5`). | Name.parquet (Name is specified by the user) |
| **L-Diversity** | Measures whether each quasi-identifier equivalence class contains a sufficient diversity of sensitive values. | `Input File 1`: anonymized dataset.<br>`Quasi-Identifiers`: attributes used to form equivalence classes.<br>`Sensitive Attributes`: confidential attributes evaluated within each class.<br>`Expected L`: minimum required sensitive-value diversity (default: `2`). | Name.parquet (Name is specified by the user) |
| **T-Closeness** | Measures whether the distribution of a sensitive attribute within each equivalence class remains sufficiently close to its distribution in the complete dataset. | `Input File 1`: anonymized dataset.<br>`Quasi-Identifiers`: attributes used to form equivalence classes.<br>`Sensitive Attributes`: confidential attributes whose distributions are evaluated.<br>`Expected T`: maximum accepted distribution distance (default: `0.2`). | Name.parquet (Name is specified by the user) |
| **Classical Privacy Evaluation** | Performs a combined classical privacy assessment. | `Input File 1`: anonymized dataset.<br>`Quasi-Identifiers`: attributes that could indirectly identify individuals (default: `Age, Gender`).<br>`Sensitive Attributes`: confidential attributes to protect (default: `Patient_Status`). | Name.parquet (Name is specified by the user) |

## Image Pipeline Components

| Component | Purpose | Input Parameters | Output |
|---|---|---|---|
| **Image Preprocessing** | Prepares medical-image slices for model training through modality selection, resizing, foreground filtering, and sampling. | `Input`: image dataset (default: `BraTS`).<br>`Modality`: image modality (default: `t2f`).<br>`Target Size`: output image size (default: `64`).<br>`Minimum Foreground`: minimum foreground pixels (default: `500`).<br>`Total Slices`: number of slices to retain (default: `10000`).<br>`Selection`: slice-selection method (default: `topk_foreground`).<br>`Seed`: random seed (default: `42`).<br>`Output`: output directory name (default: `preprocessed`). | Preprocessed image dataset |
| **DCGAN Model Training** | Trains a DCGAN model using preprocessed medical images. | `Input`: preprocessed image dataset.<br>`Image Size`: image dimensions (default: `64`).<br>`Batch Size`: training batch size (default: `128`).<br>`EMA Beta`: exponential moving-average factor (default: `0.9999`).<br>`Epochs`: training epochs (default: `100`).<br>`Generator Learning Rate`: default `0.0004`.<br>`Discriminator Learning Rate`: default `0.0002`.<br>`Output`: output directory name. | Trained DCGAN model and checkpoint |
| **WGAN-GP Model Training** | Trains a Wasserstein GAN with gradient penalty using preprocessed medical images. | `Input`: preprocessed image dataset.<br>`Image Size`: image dimensions (default: `64`).<br>`Batch Size`: training batch size (default: `128`).<br>`EMA Beta`: exponential moving-average factor (default: `0.9999`).<br>`Epochs`: training epochs (default: `100`).<br>`Gradient-Penalty Frequency`: default `16`.<br>`Gradient-Penalty Weight`: default `10`.<br>`Number of Critic Updates`: default `5`.<br>`Output`: output directory name. | Trained WGAN-GP model and checkpoint |
| **Synthetic Image Generation** | Generates synthetic medical images using a trained image model. | `Input`: trained model checkpoint (default: `trained_model/checkpoint_latest.pt`).<br>`Number of Images`: number of images to generate (default: `1000`).<br>`Batch Size`: generation batch size (default: `64`).<br>`Output`: output directory name (default: `synthetic_images`). | Synthetic medical-image collection |
| **Image Statistical Evaluation** | Compares real and generated images using statistical image-generation metrics. | `Input 1`: preprocessed real images.<br>`Input 2`: trained model checkpoint.<br>`Number of Real Images`: default `1000`.<br>`Number of Fake Images`: default `1000`.<br>`Batch Size`: default `32`.<br>`KID Subset Size`: default `500`. | Statistical image-evaluation metrics and report |
| **Image Privacy Evaluation** | Evaluates similarity and privacy risks between training, reference, and generated images. | `Input 1`: preprocessed real images.<br>`Input 2`: trained model checkpoint.<br>`Reference Split`: reference-data subset (default: `test`).<br>`Number of Training Images`: default `2000`.<br>`Number of Reference Images`: default `2000`.<br>`Number of Fake Images`: default `2000`.<br>`Batch Size`: default `32`.<br>`Number of Workers`: default `0`. | Image privacy-evaluation metrics and report |
